# 股债估值仪表盘

本仓库通过 GitHub Actions 获取市场估值数据，使用 GitHub Pages 发布单一的股债估值仪表盘。

网页地址：https://tang1273880952-dotcom.github.io/bond-timing/

## 页面内容

- 新增资金观察方向：中证500、10年国债ETF、30年国债ETF、标普500。
- 历史估值走势：中证500、科创100、北证50。
- 用不同颜色区分相对低估、中性和相对高估；最新行情日期以各卡片显示为准。

## 更新与发布

- `.github/workflows/deploy.yml`：更新中国股债估值数据和发布仪表盘。
- `.github/workflows/update-us.yml`：独立更新标普500相关数据和重新发布。
- `scripts/build_pages.py`：构建只含仪表盘的最小 GitHub Pages 发布目录，不发布测试、脚本或原始行情缓存。

首页“刷新数据”会重新读取已发布的最新快照，不会直接启动 GitHub Actions，也不保证行情源当天已有新数据。

## 不要删除的行情缓存

- `data/csi500_erp_daily.csv`：中证500真实日度 ERP 历史缓存。
- `data/csi500_erp_monthly.csv`：中证500月度历史分位样本。
- `data/csi500_index_close_daily.csv`：中证500实际收盘点位。
- `data/bse50_daily.csv`、`data/star100_daily.csv`：北证50及科创100历史估值。
- `data/china_yields_daily.csv`：国债收益率历史缓存。

这些缓存用于增量更新，不直接包含在 Pages 发布包中。网页读取 `data/latest.json`、`data/us_latest.json`，更新状态在对应 `status.json` 文件中。

## 计算口径

ERP = 100 / 指数滚动市盈率 TTM − 国债10年期收益率（标普500使用美国10年期国债收益率）。
参考分位由各自真实历史样本计算，每月使用上一个完整月份的行情修正。
10年、30年国债ETF为收益率代理判断，不等于ETF实时价格或未来回报。
绿色代表相对较便宜，不代表确定的交易信号。

## 七个行业估值模块

新增模块均位于北证50下方，顺序为证券公司、中证医疗、中证传媒、中证煤炭、食品饮料、中证白酒、中证银行。
四张PE图显示真实PE主线及3/5/10年独立历史分位；证券公司使用真实PB倍数并同样切换3/5/10年分位；煤炭、银行因尚缺历史PB倍数只展示10年PB历史分位（3/5年按钮禁用）。
由 `.github/workflows/industry.yml` 独立更新，页面“刷新数据”读取新发布快照。
医疗、传媒、食品饮料、白酒使用中证指数滚动PE（PE-TTM）；证券公司使用股叉叉公开历史PB倍数；煤炭、银行使用百分位公开最新PB与10年历史周度分位，不能由分位反推过去的PB倍数。


历史分位计算校验：所有分位水平线（含0%最低、100%最高）和当前分位使用同一组截至上一个完整自然月的日度PE样本。0%/100%是选定区间的真实最低/最高历史估值，不是最低/最高指数价格，也不代表未来的绝对底部/顶部；当前PE可以低于0%线或高于100%线。日度PE口径与等权PE、PB可能不同。


## 悬浮估值导航

页面顶部固定显示横向估值快捷栏，无需点击展开：每个指数上方名称，下方是彩色估值状态及分位；电脑端一排，窄屏左右滑动，依次直达中证500、科创100、北证50及七个行业指数。每项状态根据该图当前选择的年限计算，并随页面「刷新数据」更新。ERP 分位越高代表相对越便宜；PE 分位越低代表相对越便宜。状态颜色只是历史相对位置，不构成买卖建议。缺少真实分位数据时显示「暂无」，不会推断估值。


顶部导航会跟随滚动位置自动高亮当前正在查看的历史估值图；选中项使用加深蓝色背景、底边线和粗体名称，并加上辅助阅读属性 `aria-current="location"`。点击跳转时也会立即高亮对应指数，鼠标移开后仍保持，进入下一张图时自动切换。估值徽章的红绿状态独立于当前阅读位置。

## 数据源与维护说明

- 中证500概览用乐咕乐股PE/PB，历史图用中证指数官方PE；同日ERP和分位数可能存在源差。
- 证券公司使用真实PB倍数，3/5/10年切换重新算分位；煤炭、银行只展示有依据的10年PB历史分位；其余4个行业图使用PE-TTM。10年与30年国债ETF评分是收益率代理，不是ETF实时价。
- 标普500最新月份的PE可能属于估算，使用月度国债收益率，不能与日度价格直接视作同日交易信号。
- 发布前运行 scripts/audit_snapshot.py 检查数据状态、历史分位、日期、指数代码与来源结构；更新失败保留最后已验证数据。
- PE与国债发布不同步时，保留最新真实PE，向前匹配最多5天内的国债观测并分别标注日期；不会因国债晚一天而误用上个月PE。
- 数据日期较旧、连续超过4天没有更新尝试、最近更新失败或状态无法读取时，页面显示提示，相应快照不参与新增资金观察。中国日度数据使用10天宽限，美股月度数据使用45天宽限；长假可能触发“历史参考”提示，不等同于源数据错误。
- AKShare与Pandas固定为通过接口实测、模型与页面回归测试的版本，避免定时任务自动安装未经核验的新版本。调整依赖版本前应重新运行测试和接口核验。

### 黄金AISC成本参考

黄金卡片位于标普500之后；独立历史图位于标普500历史图之后、行业图之前，导航增加黄金入口。
卡片显示金价/AISC倍数，不套用股票PE、ERP或未经验证的百分制评分，也不混入原有股票/债券评分。

- 金价：新浪伦敦金现货XAU（日线最新观测，可能为盘中值），不是COMEX黄金期货GC；单位美元/金衡盎司。
- 成本：世界黄金协会公开的Gold Demand Trends供给报告及Metals Focus署名文章，使用全球行业季度平均AISC；完整授权成本数据库需要登录，本站未调用或绕过它。
- 参考倍数：用户自设1.3、1.5、2.2、2.7、3.0倍。价格带为当时已公开AISC乘倍数；“成本倍数”视图显示金价/AISC及五条水平参考线。
- 披露时点：成本在公开报告公布次日生效，不能回填到成本所属季度起点。沿用上次已知成本，不插值；后续披露的旧季度修订不覆盖更新季度。公开样本可能缺少更早披露，图表不是完整市场信息回测。
- 历史范围：从2020年7月首次可核验的公开成本观测生效日开始，提供1/3/5年及全部范围，不补造十年历史。公开来源含截至2026Q1的成本，每次任务继续检查最近四期公开报告。
- 更新：随中国股债任务在工作日22:00、23:00更新，并随美股任务在周二至周六08:30、10:30补查（北京时间）。中美市场工作流共享队列、开始时读取main最新状态，避免黄金快照并发覆盖。
- 校验：公开日期、生产季度、成本单位、价格品种、历史成本匹配和五档倍数运算均进入发布前审计；失败保留最后真实快照并提示。

原始公开成本来源与披露日期保存在`data/gold_aisc_public.json`；金价缓存为`data/gold_price_daily.csv`，网页仅发布`gold_latest.json`与`gold_status.json`。
AISC反映矿山维持经营成本，不是黄金价格底线或黄金内在价值。当前卡片始终显示实际采用的成本季度；公开报告样本不一定是授权数据库里的最新季度。
