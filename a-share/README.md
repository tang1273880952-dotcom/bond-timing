# A股价值筛选器（免费版）

访问：https://tang1273880952-dotcom.github.io/bond-timing/a-share/

此项目与根目录的股债仪表盘共用公开GitHub仓库，但界面、数据与运行流程独立。

## 低估值优质股 V2 筛选流程（2026-10-29）
1. **全市场快速粗筛**：独立的 `scripts/update_a_share_fast.py` 从沪深A股股票名录中抓取最新价格、PE和PB。优先尝试东财全市场，再尝试沪深分市场；接口失败时使用BaoStock轮换批次，仅获取最近行情，不重复下载10年历史。存储于 `a-share/data/quick.json`。
2. **财务复核**：`scripts/update_a_share.py` 只选择快速粗筛入围且行情不陈旧的公司，检查年报ROE、经营现金流和利润增长，过滤财务质量不符合要求的公司。自选持仓无论是否通过粗筛，都优先跟踪。
3. **深度PB Band**：只有财务质量符合门槛的候选股以及用户持仓，才查询十年历史PB；评分只有在价格、财务、历史估值完整时才生成。
4. **展示口径**：网页显示股票名录数、第一层行情有效数、粗筛入围数、深度评分核验数。粗筛入围不等于正式精选，TOP20仅在已验证且通过新版硬性门槛的深度样本内排名。
5. **自动更新**：快速粗筛北京时间周一至周五19:00（UTC 11:00）；深度财务复核与PB Band北京时间周一至周五20:00（UTC 12:00）。深度定时任务要求当天快速粗筛数据成功生成，否则停止本轮深度更新。法定非交易日可仍触发计划任务；GitHub定时启动可能延误。无额外API或服务器付费。
6. **历史可比性**：快速粗筛中东财的PE是动态口径；深度评分使用BaoStock的PE-TTM口径。二者不得直接当作完全相同的指标。PB历史带仅是历史估值位置，不保证未来价格走势。
7. **已验证首批结果**：2026-10-29初次全市场快照取得沪深A股5216只的有效价格/估值，股票名录5223只，粗筛候选2131只。后续数据与覆盖率以 `quick.json` 最新记录为准。

## 四个入口
- 精选排名：首页最多显示20只已完成新版模型核验且满足低估值硬性门槛的股票。未获得合格财报和PB历史的公司不强行评分，不强制凑满10只
- 我的持仓：手动提交GitHub表单后，在所有设备上同步
- 观察池：未买入的自选股，也不受精选排名进出影响
- PB Band：历史PB分位及对应参考价格区间（需有足够历史样本）

## 添加持仓
1. 在网页点「我的持仓 > 添加 / 修改」
2. 登录持有本仓库的GitHub账号，提交Issue Form：操作类型、6位代码、当前持仓成本（元/股）、当前总股数
3. GitHub Actions核对申请人必须等于仓库拥有者，然后更新 `a-share/data/holdings.json` 并直接重新发布GitHub Pages
4. 在网站刷新查看。仓库是公开的，成本和股数也公开

修改仓位提交同一股票最新的**总持仓股数**，而不是本次加仓数量。全部卖出请选择「删除持仓」；观察池同理。

## 免费数据
- 全市场行情：AKShare全市场/沪深分市场快照；接口不可用时退化为BaoStock从全市场名录轮换补齐最新PE、PB、价格（持仓优先），不会仅从之前聊过的股票中挑选
- 历史股价、PB、PE：BaoStock历史日K
- 财务：BaoStock利润、成长、现金流、负债季度接口
- 更新：GitHub Actions工作日北京时间19:00快速估值，20:00对粗筛合格样本财务复核并对符合质量条件者计算PB Band
- 采用增量核验，免费接口不保证每只股票每日可获得完整财务数据

## 质量规则
- 初筛范围为沪深A股，当前不纳入北交所。ST风险、非正盈利或严重财务恶化不自动推荐
- 估值35%，经营质量35%，增长15%，财务风险15%。评分只用于已通过硬性过滤的非金融企业。 
- 硬性门槛：PE-TTM (BaoStock) >0且≤35倍、PB >0且≤4.5倍、历史PB分位≤35%、最近完整年ROE≥8%、已公布最近2—3个年度ROE最低值≥5%、经营现金流/净利润≥0.8、最近净利润同比增长≥-25%、资产负债率≤75%。任一必要数据缺失则不入榜。
- 轻量初筛仍放宽为PE≤45、PB≤6，以避免过早排除；最终必须通过严格门槛。快速阶段的动态PE不能代替深度评分的TTM PE。
- 多年ROE来自逐年公布的年报数据；免费源暂不保证扣非净利润、ROIC、应收存货及商誉数据齐全，因此**尚未实现完整价值陷阱检测**，不得据此宣称彻底排除了风险。
- 当前评分权重只是一组可解释的研究规则，尚未进行严格无前瞻偏差回测，不代表未来收益率。
- 经营质量参考上一个完整会计年度的ROE、经营现金流与净利润之比；增长参考最近可取得的已披露季度；财务风险对非金融企业采用负债率的保守规则
- 金融行业按行业字段、名称和常见证券代码组合识别并排除；中国平安、中国太保、东方财富等名称不含典型金融词的股票不会被当作普通制造企业评分。金融行业独立估值模型尚未完成。
- 新下载的PB历史图按每个月份**之前已出现的PB数据**计算滚动分位，再乘该月对应的估算BPS；旧缓存若未更新仍显示旧静态曲线，待下一轮历史刷新升级。现价PB分位由最近一次历史下载计算，数据日期可能晚于或早于最近快照，应检查日期，不是实时估值。
- 未取得完整财报、合理历史数据与新鲜报价时不生成综合分，网站显示未完成
- 页面展示「估值低位·重点研究」「符合条件·继续观察」「暂不进入精选」等条件信息，不自动下买卖指令。持仓独立跟踪，未通过新股筛选不意味着立即卖出。
